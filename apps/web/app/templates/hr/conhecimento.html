No computador do usuário (stdio)

  1. Abra o Claude Code na pasta do projeto. O arquivo .mcp.json da raiz já registra o servidor kronos.
  2. Aprove o servidor quando o Claude Code pedir e confira com claude mcp list.
  3. Se o python do PATH não for o do projeto, troque command pelo caminho do python.exe do .venv.
